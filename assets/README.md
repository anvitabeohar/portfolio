# Visual assets

Upload your images here using the file names below and they will appear on the site
automatically (JPG shown; if you use PNG/WebP, update the matching `src` in the HTML).

| File | Used for |
|---|---|
| `images/hero.jpg` | Large image under the homepage headline (optional) |
| `images/about.jpg` | Portrait in the About section |
| `images/projects/project-1.jpg` … `project-4.jpg` | Project card covers + case study header |
| `images/projects/project-N-process.jpg` | Process image inside case study N |
| `images/projects/project-N-final.jpg` | Final design image inside case study N |
| `icons/favicon.png` | Browser tab icon (e.g. 64×64) |
| `docs/resume.pdf` | "Resume" link in the navigation |

Tips: keep images under ~500 KB (export at 2× width ~1600px, compress with squoosh.app).
